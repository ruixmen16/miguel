# Proyecto Miguel

## Estructura

- FRONT: aplicación móvil web con React + Vite + Tailwind
- BACK: API en Node.js para autenticación y envío de reportes

## Ejecutar frontend

```bash
cd FRONT
npm install
npm run dev
```

## Ejecutar backend

```bash
cd BACK
npm install
npm run dev
```

## Notas
